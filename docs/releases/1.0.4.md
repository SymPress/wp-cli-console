# 1.0.4 release candidate

This patch addresses the 1.0.3 production archive's Plugin Check findings at the
native WP-CLI process boundary. It retains argument-array execution without a
shell and incremental stdout/stderr pipe handling. Documented inline PHPCS
exceptions cover only the reviewed process and private pipe operations.

Forwarded CLI host environment values now accept DNS names, IP addresses and
valid optional ports; malformed values fall back to `localhost`. Process tests
cover accepted and rejected host tokens, inherited environment fallback and
literal shell metacharacters. Option-looking positional values remain rejected
before reaching the runner.

The archive caller, pinned reusable workflows and mandatory archive-check gate
remain unchanged. Publish a new 1.0.4 tag and archive only after review and the
fresh hosted archive check; do not retag or replace 1.0.3. Local package QA and
source-sniff checks do not establish that a hosted archive has passed.
